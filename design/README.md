# Design

`preview.html` ist eine eigenständige, klickbare Vorschau der Mobile-App im
finalen dunklen „Schwarz-Gold"-Design (edler Premium-Look). Einfach im Browser
öffnen – Suche, Sortierung, Detailansicht und Merkliste sind voll interaktiv und
nutzen dieselbe Demo-Suchlogik wie das Backend.

Die Datei dient als visuelle Referenz für die echte React-Native-Umsetzung in
`../mobile/`. Farb- und Abstands-Tokens leben dort in `src/theme.ts`.
